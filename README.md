## 🎯 About the Project

Welcome to my **Ethical Hacking & Cybersecurity Portfolio** — a single-page, fully responsive website designed to showcase my professional profile as a **Cybersecurity Specialist** and **Professional Penetration Tester**.

The site features a **hacker-style terminal UI** with a dark cyberpunk aesthetic, animated Kali Linux dragon logo, rotating security quotes, and a clean, modern layout. It was built entirely with **vanilla HTML, CSS, and JavaScript** — no frameworks, no build tools, no dependencies except Font Awesome and Google Fonts.

> 💡 **"More Secure, More Care"** — my personal security philosophy.

---

## ✨ Features

### 🎨 Design & UI
- **🖥️ Terminal-Style Header** — macOS-like traffic light dots with a `root@prathyu:~$ whoami` prompt
- **🐉 Animated Kali Linux Logo** — GIF-style CSS animations (floating dragon, pulsing glow, rotating dashed ring, expanding pulse ring)
- **🌊 Cyberpunk Aesthetic** — Scanline overlay, CRT-style glow, blue-dominant color palette (`#58a6ff`)
- **📱 Fully Responsive** — Optimized for desktop, tablet, and mobile devices
- **🖱️ Interactive Hover Effects** — Every card, button, and tag responds to hover with glows and lifts

### 🛠️ Functionality
- **🔄 Rotating Quotes Carousel** — Auto-rotates every 5 seconds with clickable indicator dots
- **⌨️ Typing Cursor Animation** — Blinking cursor in the introduction section
- **📧 Icon-Only Social Buttons** — WhatsApp, Telegram, and TryHackMe with hover tooltips
- **🎨 Custom Scrollbar** — Blue-themed scrollbar matching the site's aesthetic

### 📋 Content Sections
- **Profile Hero** — Animated avatar, name, and title badge
- **Terminal Introduction** — `cat introduction.txt` styled intro block
- **Certifications Owned** — OSCP, CEH, CompTIA Security+, AWS Security, eJPT, Kali Linux
- **Rotating Quotes** — Security philosophy and famous cybersecurity quotes
- **Achievements** — Gold-accented cards (TryHackMe Top 1%, CVE Discovery, CTF Winner, etc.)
- **Stats Grid** — 250+ vulnerabilities, 15+ bug bounties, 6+ certifications, 40+ CTFs
- **Arsenal & Expertise** — Interactive skill tags
- **Projects** — VulnScout, Wi-Fi Pentest Toolkit, Bug Bounty highlights
- **Contact Section** — Email, PGP key, WhatsApp, Telegram, TryHackMe
